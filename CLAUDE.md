# CLAUDE.md

The VequIR shop, built the unframe way — read `.claude/skills/unframe/SKILL.md`
before changing structure. Key rules:

- Source lives in `ui/`; `ui/dist/` is generated by `make dev` and git-ignored.
- One component per file in `ui/comps/`: a pure template, one `mount(...)`
  into a global named after it, and its handlers. Register each in
  `make/js.map` and add its `/* {{name-js}} */` token to `ui/layout.js`.
- Templates are pure string builders; escape data with `esc()`.
- **Update the README's Models section in the same change** whenever a model
  or field changes, and keep `ui/demo.js` in step (bump `DEMO_VERSION`).
- Only `make dev` (offline) exists for now. Back-end code, when it arrives,
  goes inside `//online-start … //online-end` or a trailing `//online`.
- Every pushed branch deploys (staging) via `.github/workflows/pages.yml`, with `BASE=/vequir/`
  (anroleroux.co.za/vequir). No CNAME — the user site's domain covers it.
